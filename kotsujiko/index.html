事故対応が止まるのは、だいたい同じ場所です

交通事故の問い合わせが入ったとき、受付が「院長に代わります」としか言えない。院長が不在の日に、問い合わせが止まる。スタッフによって説明が違う。取りこぼしの多くは、技術ではなく知識の偏りで起きています。

そして、その知識自体が、こんな話で止まっていないでしょうか。

  • 「交通事故の患者さんは、月15日は通ってもらわないと」
  • 「事故から2週間以内に病院に行かないと、自賠責は使えない」
  • 「一括対応になれば、施術費は全部通る」
  • 「自賠責の120万円までは無料」

これらが法律で決まっていることなのか、保険会社の運用なのか、誰かの経験則なのか。区別して説明できる方は、どれくらいいらっしゃるでしょうか。

患者さんに誤った説明をすれば、信頼を失います。逆に、根拠をもって説明できる院は、それだけで選ばれます。本書は、その区別をつけるための教材です。

「確認できませんでした」の意味

調べ足りないという意味ではありません。探した範囲（どの法令のどの条文を見たか）を明記したうえで、根拠が存在しないという調査結果として書いています。

こんな院に向いています

  • 交通事故患者を受け入れているが、制度を体系的に学んだことがない
  • 患者からの質問に、その場の判断で答えてしまっている
  • 院長だけが対応できる状態で、問い合わせの電話を全部自分が取っている
  • 保険会社から「そろそろ治療終了で」と言われたときの返し方が、毎回違う
  • 受付スタッフが交通事故の電話を取れず、取り次ぐしかない
  • 分院があり、院ごとに対応や説明がばらついている
  • 新しくスタッフが入るたびに、同じ説明を一から繰り返している
  • 業界セミナーや同業者から聞いた話の真偽を確認したい
向いていない方

示談交渉・賠償額の算定を代行する方法を知りたい方／通院日数や部位数を増やす方法を求めている方／保険会社と対立して請求を通す手法を探している方

よくあるご質問

交通事故対応の経験がまったくないのですが、理解できますか。
第1部は制度の基礎から始まります。専門用語は初出時に必ず説明しています。全章が「この章で学ぶこと → なぜ重要か → 基礎知識 → 実務での考え方 → 具体例 → よくある誤解 → 現場での注意点 → チェックリスト → まとめ」という同じ構成なので、章をまたいでも読み方が変わりません。
逆に、長く交通事故対応をしてきました。新しく学ぶことはありますか。
本書の中核は、業界で語られている話を法令と告示の原文で検証した結果です。「月15日通院」「実治療日数の2倍」「2週間以内の受診」について、何が確認でき、何が確認できなかったかを、出典とともに記載しています。また第3部の広告規制は、知らずに運用されている院が多い領域です。
受付スタッフに読ませたいのですが、難しくないですか。
受付スタッフが知っておくべき範囲を第3部で線引きしてあります。受付スタッフ向けの説明資料（1枚）を用意してあるので、まずこれを渡していただく形が現実的です。
